# Discovery -> Demo -> Close

## Discovery
- proceso actual del cliente
- costos ocultos y errores frecuentes
- impacto mensual estimado
- decision makers y timeline

## Demo
- mostrar solo casos de alto impacto
- conectar feature -> resultado economico
- definir plan de implementacion corto

## Cierre
- propuesta con alcance, precio y fecha de inicio
- resolver objeciones (riesgo, tiempo, integracion, costo)
- siguiente paso con fecha comprometida
